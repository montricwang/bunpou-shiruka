# 文法？知るか！

日语语法学习应用。目前以交互原型逐步验证语法图谱的交互方式，语法规则与数据仍在探索中。

## 项目目录

- `frontend/`：学习界面与交互。
- `backend/`：服务端逻辑与数据处理。
- `docs/`：需求、设计与开发文档。
- `data/raw/`：采集的原始语法资料。
- `data/processed/`：整理后的结构化数据。

原始资料和处理结果默认只保存在本地。确认来源、授权和发布范围后，再决定是否纳入版本控制。

## 交互原型

直接在浏览器打开 [`frontend/morphology-demo.html`](frontend/morphology-demo.html)，无需安装依赖。页面提供浅色 / 夜间模式切换（记住选择），以及「書く」「まい」两条探索路径。

「書く」的词干与词尾处于同一个虚线语法单位中：点击「く」，词干留在左侧，右侧纵向列出六类活用形的八个词尾候选，原来的「く」也包含在内。终止形与连体形同为「く」，假定形与命令形同为「け」，但按活用形分别决定后续接续。选中候选后原地更新词尾、保留可重新选择的分支；接入「ない」「まい」等后接成分才新建语法单位。「ない」内部仍可继续变化并接续「た」「て」。分组和字形可拖动、折叠。

动词活用候选缩成更紧凑的单列，活用形名称与假名之间的距离也收近。当前「ない」「ます」「せる」三种助动词同样可在自己的虚线框内展开活用形，再从选定形式向右接续。例如：「書かなければ」「書きました」「書きません」「書きましょう」「書かせられる」「書かせます」。现阶段仅录入用于验证交互的接续关系，尚不支持任意层数的助动词递归展开。

「まい」可按教材中的「意义 / 接续法」探索。意义分为否定推量、否定意志、否定劝诱及禁止（＋ぞ）；接续法按照动词、助动词及对应活用形细分。例句数据暂不接入，调研见 [Issue #4](https://github.com/montricwang/bunpou-shiruka/issues/4)。

本原型只验证交互和少量教材样本，语法规则库尚不完整。使用 `node frontend/morphology-demo.test.cjs` 运行无需第三方依赖的交互模拟测试。

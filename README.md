# 文法？知るか！

日语语法学习应用。目前处于需求与设计讨论阶段。

## 项目目录

- `frontend/`：学习界面与交互。
- `backend/`：服务端逻辑与数据处理。
- `docs/`：需求、设计与开发文档。
- `data/raw/`：采集的原始语法资料。
- `data/processed/`：整理后的结构化数据。

原始资料和处理结果默认只保存在本地。确认来源、授权和发布范围后，再决定是否纳入版本控制。

## 交互原型

直接在浏览器打开 [`frontend/morphology-demo.html`](frontend/morphology-demo.html)，即可体验单张可展开的语法图谱。当前有「書く」「まい」两个起点：前者逐步展开词尾变化与后接成分，后者从助动词向前探索语法分类及接续条件。节点可拖动，连线跟随移动；初始「書く」显示为一个整体，进入活用后在节点内部拆成「書｜く」，选中「か」则显示「書｜か」。点击节点展开或折叠，点击信息标记查看简短说明。

原型暂用少量样本规则验证交互，尚未建立完整语法规则库。

# 文法？知るか！

日语语法学习应用。目前以交互原型逐步验证语法图谱的交互方式，语法规则与数据仍在探索中。

## 项目目录

- `frontend/`：学习界面与交互。
- `backend/`：服务端逻辑与数据处理。
- `docs/`：需求、设计与开发文档。
- `data/raw/`：采集的原始语法资料。
- `data/processed/`：整理后的结构化数据。

原始资料和处理结果默认只保存在本地。确认来源、授权和发布范围后，再决定是否纳入版本控制。

## 交互原型

直接在浏览器打开 [`frontend/morphology-demo.html`](frontend/morphology-demo.html)，即可体验单张可展开的语法图谱。当前有「書く」「まい」两个起点：前者逐步展开词尾变化与后接成分，后者从助动词向前探索语法分类及接续条件。虚线框表示语法单位，框内的「書」「く」等是彼此独立、可单独拖动的字形节点；框表示它们共同构成的活用形。选择「か」后，分组变为「書｜か」；接入否定助动词后，另一个分组展示「な｜い」，继续展开可选择「な｜かっ」并接上「た」。拖动字形或整个分组时，连线会跟随更新。点击虚线框展开关系，左上角的 − / + 可折叠或展开内部字形；信息标记提供简短说明。

原型暂用少量样本规则验证交互，尚未建立完整语法规则库。

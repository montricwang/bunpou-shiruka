# DevLog · 2026-10-21

今日完成「文法？知るか！」的首轮图谱交互验证，并启动日本本土语法体系与结构化数据源调研。**前端暂时封板，下一阶段先验证语法资料，再设计数据库。**

## 交互原型

[PR #3：词尾变化与接续关系的交互原型](https://github.com/montricwang/bunpou-shiruka/pull/3) 持续迭代，当前仍**开放、未合并**：

- 从「書く」开始，词干和词尾是语法单位内的独立字形节点；活用时更新同一语法单位，接续时才新增语法单位，避免将「書く」「書か」画成两个独立的动词。
- 词尾候选改为**词干右侧的一列**，保留学校文法的六种活用形及八个展示位置：未然「か／こ」、连用「き／い（音便）」、终止／连体「く」、假定／命令「け」。相同字形允许对应不同语法功能和后接条件；已选分支高亮，其他候选仍可切换。
- 每个语法单位以虚线分组承载，可折叠；字形、分组可拖动，连线跟随位置更新。添加夜间模式，保存用户选择。
- 收紧活用列：候选纵向行距从 **61** 缩至 **47**（SVG 坐标单位），内层虚线框宽度从 **212** 缩至 **172**，活用形标签靠近假名。
- 不只处理动词：以「ない」「ます」「せる」验证**助动词自身的活用与后续接续**，涵盖「書かなかった」「書かなければ」「書きました」「書きません」「書きましょう」「書かせられる」等少量路径。
- 「まい」另设**意义／接续法**两条探索方向：意义包括否定推量、否定意志、否定劝诱和禁止；接续法按前接词类及活用形逐层查看。例句暂未导入。

上述内容是用于验证交互的数据与规则样本，**并未完成对日语语法的系统校对**。JavaScript／HTML 基本检查、模拟 DOM 的交互回归以及 PR 的 GitHub Actions 通过；**尚未进行用户确认的真实浏览器视觉验收**。前端还有间距、连线和图形交互需要调整，但今天决定暂时保留现状。

## 语法资料与数据库方向

现有 Excel 主要根据皮细庚著作整理。今天决定**保留其作为对照资料，不直接将这套分类迁入数据库**；尚无逐条证据证明整本书过时或有误。

第一轮调查见 [《日本本土语法体系与数据源：首轮调查》](../research/japanese-grammar-sources.md)，记录于 [Issue #4](https://github.com/montricwang/bunpou-shiruka/issues/4)、[Draft PR #5](https://github.com/montricwang/bunpou-shiruka/pull/5)：

- 日本**学校文法**与面向外国学习者的**日本语教育文法**在切分、活用说明和教学组织上存在差异，不能直接默认其中一套名称是数据库唯一真值。
- 日本語記述文法研究会《現代日本語文法》优先作为现代描述语法的学术参照；国际交流基金《まるごと》作为学习者文法组织方式的参考。受版权保护的教材正文不可直接视作开放数据。
- 国立国语研究所 **UniDic** 是首选的结构化**词形数据验证对象**（词类、活用类型、活用形等），但不能据此认为它提供所有合法接续关系。
- **BCCWJ** 可供后续用例核查；在线例句库、JLPT 开放数据暂时作为后续来源候选。使用任何材料前需核实版本、来源、许可证与可否再分发。

因此，数据库暂**未开始施工**：先核对分析体系与来源，明确「词形事实」「接续规则」「学习者展示」各自的职责，再决定是否采用 SQLite 等存储工具。不将原型里的示例关系直接当作完整、权威的接续表。

# 日本本土语法体系与数据源：首轮调查

调查日期：2026-10-21。状态：**资料选型研究，不代表已选定唯一语法体系；尚未建立数据库、导入语料或证明接续规则完整。**

## 一、先确定研究问题

现有《日语.xlsx》来自皮细庚著作的整理，保留作**待核对的中文教材对照资料**。目前没有逐项核验其原始版本、活用体系和具体错误，不宜简单判定整本书已经过时。

真正的问题是：学习者界面需要展示什么样的语法分类，底层需要什么样的可检验、可追溯的词形和接续关系？

国立国语研究所介绍指出，日本的学校文法与对外日本语教育文法存在显著差异。同一个「書く」，学校文法可写成词干「書（か）」＋词尾「く」，而教学文法也可以将 *kak-* 看作词干、*-u* 等看作变化部分。**当前原型的「書｜く」只是一种教学展示，不应该固化为数据库中唯一的形态分析。**

参考：[国立国語研究所《外国人が日本語を学ぶときの「文法」は…》](https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-168/)。

## 三、机器数据及授权

- UniDic 官方文档对应 `pos1..pos4`（品词分层）、`cType`（活用型）、`cForm`（活用形）、`lemma`（语汇素）和 `orth`（出现字形）；例中「凍り付け」可判为「五段-カ行／命令形」。该形态分类**未必与学校文法的六形一一同名、同粒度**，需要样本映射。
- **官方现代语 UniDic**（规定适用版本）提供 GPL v2 / LGPL v2.1 / 修正 BSD 三重许可，官方明确说明可用于商业用途。下载和再分发须保留对应许可、注明来源；实际版本另行固定。
- 《まるごと》资源可作对照参考。参考教材的编排原则不等于获得其正文数据的复制许可。《いろどり》的官方条款明确限制另制教材。
- BCCWJ 是查证真实用例的资源，不直接提供完整语法关系表。其站点说明商业利用需要另行沟通，引用须符合相关要求。

官方条款：[UniDic 下载与许可](https://clrd.ninjal.ac.jp/unidic/download.html)、[UniDic 商业使用](https://clrd.ninjal.ac.jp/unidic/commerce_use.html)、[BCCWJ 使用方式](https://clrd.ninjal.ac.jp/bccwj/index.html)。

## 四、架构结论（仅为建议）

暂不选择单一教材表作为数据库标准，先明确以下**职责区分**：

1. **词形事实**：语汇素、词类、活用类型、实际形态、语法来源（UniDic 可供检验）。
2. **分析体系**：标识「学校文法」「日本语教育」「UniDic」等方案，同一词形允许不同分解和标签，前端选择呈现方式。
3. **接续规则**：独立保存「前接条件 → 后接语法单位」；不能直接把频繁共现或分词结果推断为规范接续。
4. **教学显示**：根据学习者需要映射概念、难度及说明，不复制受版权保护的表格、解释和例句。

要明确保留相同字形、不同活用功能的区别（如「書く」终止形／连体形）。此外「基本形／辞书形」「连用形音便」「て形」等命名可能属于不同描述粒度，避免强行同构。

## 五、下一步验证（未执行）

1. 下载一份**确认许可证和版本**的现代书面语 UniDic，实测字段与输出，不仅凭文档推测。
2. 以「書く／食べる／高い／静かだ／ない／ます／せる／まい」做最小对照：展示 UniDic 形态分析、学校文法解释、教育文法解释之间的实际差异；分别核对活用和接续，不混为一事。
3. 优先检验难例「まい」的前接条件，以及「書く」终止形／连体形等同形异功能，不提前假设现有原型全部正确。
4. 列出真实需要人工补充的关系和缺口，再设计最小数据库表；在此之前不全量迁入 Excel，也不批量采集例句。

本轮只形成研究结论，没有验证上述所有具体词形，也没有确定最终语法分类标准。
